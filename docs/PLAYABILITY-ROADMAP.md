Owner approved all seven recommendations on October 8, 2026. Preserve deep solo play, optional multiplayer, unobtrusive IDs and iPhone/Android goals.

| Improvement | Current implementation | Remaining work |

| Better combat feel | Enemy telegraphs, Focus, guard/evade, class traits and creature illustrations exist | Distinct expanded behaviors, richer hit feedback, physical gesture response/acceptance |

| Clear next objective | Local server-derived nextObjective, browser Journey/Hall and native Journey display | First-session Field prominence and navigation consistency |
| Easy friend play | Existing private real-player PvP and guilds | Friend invitations/list, small parties/shared quests, PvP rematches; no simulated nearby people |
| Polished exploration | GPS freshness, stale-map cleanup, explicit recenter, reconnect safety, lower-frame-rate effects | User battery controls, screen-off/native alerts, real geographic world and device verification |

These new features are not yet deployed.
