# v0.15 Quest Director

The personal Journey now contains one adaptive Ordinal Directive. The server chooses hunting, discovery or Field recovery from the Wayfarer's Calling, current regional threat/corruption and a deterministic personal rotation. Moving to another region generates a local objective rather than carrying an unrelated task across the world.

Progress is calculated from authoritative post-assignment activity baselines. Old accomplishments cannot be replayed for rewards. Completed directives grant XP, gold and reputation, write a bounded personal/world memory and alter the region: hunting lowers threat, discovery raises prosperity and Field stabilization raises order. A player can reroute once per UTC day, and rerouting discards progress on the previous directive.

Browser/PWA and native iPhone Journey screens show the same compact card, progress, consequences, claim and reroute controls. The feature preserves the full solo path and does not create public countdowns, community meters or required grouping.

Automated HTTP coverage verifies assignment, adaptation, daily reroute protection, premature-claim rejection, verified progress, exact rewards, regional consequences and one-time regeneration. Physical iPhone acceptance, signed distribution and production deployment remain separate gates.
